## 🛠️ MCP Tools Exposed
- `evaluate_carmack_liability_prima_facie`: Verify 3 elements of prima facie cargo damage case: in good condition at origin, damaged upon delivery, and dollar damages.
- `generate_carmack_freight_claim_notice`: Draft formal 9-month statutory claim letter under 49 C.F.R. § 1005 for immediate carrier payout.
